## Featured Project

### Kisahmu

A digital wedding invitation SaaS designed to make creating beautiful wedding invitations simple and flexible.

**Built with:**

`Laravel` · `Vue 3` · `Inertia.js` · `Tailwind CSS` · `MySQL`

Key features include:

- Customizable invitation themes
- Couple & event management
- RSVP system
- Gallery & Love Story
- Custom backsound
- Gift / bank account information
- Live streaming integration
- Guest-specific invitation links
- Cloud-based media storage
